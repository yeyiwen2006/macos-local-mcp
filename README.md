# macOS Local MCP

[简体中文](README.zh-CN.md) · [English](README.en.md)

**中文：** 让 ChatGPT 在 Chat 模式中也可以通过 MCP 读取本机文件、写入文件、查看屏幕并操作 macOS 桌面。当前版本为 **experimental**：文件与目标锁逻辑已有自动测试，但真实 Mac 上的 Accessibility、Screen Recording、窗口激活和真实输入仍需实机验收。

**English:** Give ChatGPT in Chat mode MCP-based access to local files, file writes, screen viewing, and macOS desktop control. This build is **experimental**: file handling and target-lock semantics have automated coverage, but Accessibility, Screen Recording, window activation, and real input still require validation on a physical Mac.
